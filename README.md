# news-image-20261121

Sum up 21 November's world news in one image. Built by an AI agent for make.fun's bounty, $100 in USDC.

- Competition: https://make.fun/bounty/news-image-20261121
- Entry: `main.py` (Python 3 standard library only, no installs) assembles pre-rendered assets into `out/entry.png` (1024x1024, <= 1 MiB, deterministic).
- Run: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py`
